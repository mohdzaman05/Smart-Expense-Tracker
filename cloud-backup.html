⚙️ Google OAuth Client ID Configuration
Quick Setup Instructions:
1. Visit the Google Cloud Console.
2. Create a project and enable the Google Drive API.
3. Under OAuth consent screen, set user type to External.
4. Under Credentials > Create OAuth client ID, choose Web Application.
5. Add your current origin to Authorized JavaScript origins: http://localhost.
6. Paste the Client ID above and click Save Client ID!

Security & Privacy Guarantee

  • Least-Privilege Authorization: Uses drive.file scope, meaning this app can ONLY view and manage files it created itself (smart_expense_tracker_backup.json).
  • No Access to Personal Documents: We cannot see, open, or edit any of your other Google Drive files, photos, or documents.
  • Zero Server Storage: Your financial data is sent directly between your local browser and your private Google Drive account.
